# Licence texts

Standard texts (from the SPDX license list, CC0) of the licences that
`esp-idf-sbom license` reports for the firmware: Apache-2.0,
BSD-2-Clause-FreeBSD, BSD-2-Clause-Views, BSD-3-Clause, CC0-1.0, MIT,
Unlicense. It also reports MPL-2.0 for ff-eink's own files; that text is
`../LICENSE`, which every release attaches as its own asset. That report is not complete on its own: the release also copies
the original licence files of cJSON, http_parser, lwIP, Mbed TLS and newlib
from ESP-IDF into `LICENSES/upstream/`. Copyright holders are listed in the
release asset `FIRMWARE_LICENSES.txt`. See ../THIRD_PARTY_NOTICES.md.
